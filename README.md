# S.K — Premium Men's Fashion E-Commerce

A portfolio-quality Next.js/TypeScript e-commerce demo based on the supplied S.K specification.

## Run locally

1. Install Node.js 18+.
2. Open this folder in VS Code / terminal.
3. Run:
   ```bash
   npm install
   npm run dev
   ```
4. Open `http://localhost:3000`.

## Included

- Responsive premium men's fashion storefront
- 50 demo products with INR pricing
- Search, category pages, sale and new-arrival views
- Product detail pages with variants
- Persistent cart and wishlist via localStorage
- Demo checkout
- Account, About, Contact, Size Guide, Shipping pages
- Admin dashboard mock with KPI cards, inventory/product table and sales chart
- SEO metadata and accessible semantic structure
- Unsplash-hosted demo fashion photography
